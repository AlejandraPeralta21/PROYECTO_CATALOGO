PLANET CHICKEN · GUÍA PARA USARLO EN EL CELULAR

1. Extrae PLANET_CHICKEN_CELULAR.zip en una carpeta. Para una vista rápida puedes abrir index.html; el respaldo incluido muestra el catálogo. Para instalar como PWA sigue el paso 3.

2. Para ver la página en el teléfono mientras la computadora y el teléfono usan la misma Wi-Fi:
   - En la computadora, abre PowerShell dentro de la carpeta extraída.
   - Ejecuta: py -m http.server 8000 --bind 0.0.0.0
   - Busca la dirección IPv4 de la computadora con ipconfig.
   - En el teléfono abre: http://DIRECCION-IP-DE-LA-PC:8000
     Ejemplo: http://192.168.1.25:8000
   - Deja la computadora encendida y el servidor abierto mientras lo usas.

3. Para instalarlo como PWA y usarlo offline en el teléfono, publícalo en un sitio con HTTPS. La dirección local por HTTP sirve para revisar la vista, pero Android/iPhone normalmente no permite instalar el service worker desde una IP local. Ya publicado en HTTPS, abre el sitio en Chrome o Safari y elige “Instalar aplicación” o “Añadir a pantalla de inicio”. Abre el menú y las imágenes una vez con conexión; luego activa modo avión para comprobar el uso offline.

4. La carpeta assets/images/products está organizada por tipo:
   chicken, burgers, wings, combos, drinks y sides. Los combos de pollo muestran fotos de pollo; los combos Five Burger muestran el combo de hamburguesa; Wings muestra alitas. Un mismo tipo de foto puede compartirse entre variantes del mismo producto porque el proyecto no contiene una fotografía distinta para cada combo.

5. El proyecto no incluye un servidor de pedidos. Enviar un pedido sin conexión lo guarda como pendiente en el dispositivo; para que llegue al restaurante se necesita conectar una API.

Si el comando py no existe, usa la extensión Live Server de Visual Studio Code para la vista local, o publica el sitio en HTTPS para instalar la PWA.
